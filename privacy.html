プライバシー ポリシー

最終更新：2026年11月19日

利用者

gmail-sub0209 を利用するのは開発者本人だけです。第三者の Google アカウントのデータは扱いません。

扱うデータ

Gmail API を通じて、開発者本人のメール（本文、件名、宛先、ラベル）を読み取り、下書きの作成、送信、ラベルの変更、ゴミ箱への移動を行います。

保存と共有

  • 認証情報（アクセス トークン）は開発者本人のパソコンにだけ保存します。
  • メールの内容を外部のサーバーに保存したり、第三者に販売・共有したりすることはありません。
  • 広告目的での利用はしません。

Google ユーザーデータの取り扱い

Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセスを取り消せます。

English summary

gmail-sub0209 is used only by its developer to access their own Gmail account. Credentials are stored only on the developer's own computer. Email data is not stored on external servers, sold, or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account settings.
